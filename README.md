# weather-tracker1
Nov 23-30 Weather in Yosemite
This project tracks daily high and low temperatures for camping in Yosemite across the November 23–30 date range and compares upcoming weather against past conditions. I built it to turn a data science workflow into a public portfolio project on GitHub and help plan cold-weather camping gear and expectations. It uses historical archive data from the last five years alongside a seven-day forecast pulled from the Open-Meteo API and saved as CSV files.
